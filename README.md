# Расходы

Личный учёт расходов в сомах и долларах. Веб-приложение (PWA) для iPhone: работает без интернета, данные хранятся на телефоне. По желанию включается синхронизация с личным облаком (Supabase): вход по почте в разделе «Ещё».

- Быстрый ввод: набрать сумму и нажать категорию.
- Счета: наличные, МБАНК и любые свои.
- Курс доллара задаётся вручную, итоги считаются в сомах.
- Список операций с правкой и удалением, итоги за день и месяц.
- Резервная копия в файл и восстановление из файла.

Без сборки: обычные HTML, CSS и JavaScript. Для локального запуска: `python3 -m http.server` в папке проекта.

## Облачная синхронизация

`sync.js` отправляет изменения в Supabase и забирает чужие. Приложение сначала пишет в IndexedDB и отмечает изменение в очереди `outbox`, поэтому без сети ничего не теряется. При конфликте побеждает более поздняя правка. В коде лежит только открытый (publishable) ключ; доступ к строкам ограничен правилами базы (RLS): каждый пользователь видит только свои данные. Схема базы: `supabase/schema.sql`.
